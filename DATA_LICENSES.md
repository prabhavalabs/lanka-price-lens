# Data licenses

The MIT license applies to source code only. Every imported dataset keeps its
upstream license, attribution, retention, and redistribution conditions.

No source data may enter a public release unless its manifest has
`rights_status` set to `approved_open` or `approved_permission` and includes a
reviewed evidence reference.

HARTI Daily Food Commodities Bulletin data is approved for non-commercial data
preparation under operator-held permission. It is not licensed under MIT and
must not be commercialized. See `docs/source-permission.md`.
