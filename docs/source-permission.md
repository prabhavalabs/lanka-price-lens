# HARTI source permission

On 2026-08-17, the repository owner confirmed that permission had been received
to download HARTI Daily Food Commodities Bulletin PDFs for data preparation.
The permission is limited to non-commercial use. The underlying confirmation is
held privately by the operator and is not committed to this public repository.

The MIT license covers the application code only. It does not relicense HARTI
source data. Raw PDFs are retained in a private Cloudflare R2 bucket for
non-commercial data preparation and are not committed to or redistributed by
this repository. The foundry stores retrieval metadata, checksums, extraction
evidence, and prepared observations.
The permission scope must be reviewed annually and before any public data
promotion or commercial use.
